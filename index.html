YouTube to Notion summarizer

Live, private tool

Paste a YouTube link and get structured Czech notes saved to Notion. I use it for science, news and educational videos I want to understand without watching.

  • Transcript fallback chain: caption extractors first, then Supadata API, then yt-dlp, with manual paste as a last resort
  • Duplicate check: looks in Notion before generating, so the same video is never paid for twice
  • Live progress: the server streams each stage as NDJSON, with percentage and time remaining
  • Cost tracking: estimate before, real cost from token usage after, monthly overview

Node.js, Express 5, vanilla JavaScript, OpenAI API, Notion SDK, Vercel
